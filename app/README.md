# Rebecca Transport & Services - application (lot 2 : espace client)

- Outils : React + Vite
- Développement : `npm install` puis `npm run dev`
- Version finale (production) : `npm run build`, dossier `dist`
- Tous les prix et toutes les règles : `src/pricing/config.js` (base tarifaire unique)
- Moteur de calcul : `src/pricing/engine.js`
- Calendrier juif (Chabbat et fêtes) : `src/pricing/calendrier.js`
